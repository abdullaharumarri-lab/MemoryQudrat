# MemoryQudrat 🧠 — رفيق المذاكرة الذكي بالتكرار المتباعد

بوت تيليجرام لإدارة وتتبع المذاكرة والمراجعة الذكية وفق منحنى النسيان (Spaced Repetition) لطلاب القدرات، مع نظام كويزات يدوي دقيق 100% بدون أي تخمينات أو أخطاء.

## ✨ المزايا الرئيسية
- 📖 **تسجيل المذاكرة اليومية:** اكتب ما ذاكرته اليوم مع ملخص أو ملاحظات، وسيقوم البوت بجدولة مراجعاته تلقائياً.
- 🔁 **نظام التكرار المتباعد الذكي:** جدول مراجعات دقيق وفق منحنى إبنجهاوس للنسيان:
  - المرحلة 1: بعد يوم (تثبيت الحفظ الأولي)
  - المرحلة 2: بعد 3 أيام
  - المرحلة 3: بعد أسبوع
  - المرحلة 4: بعد أسبوعين
  - المرحلة 5: بعد شهر (تثبيت دائم في الذاكرة طويلة المدى 🌟)
- 🎯 **تقييم المراجعات التفاعلي:** كروت مراجعة ذكية مع أزرار:
  - `[✅ راجعت وأتقنت]`: ترقية للمرحلة التالية.
  - `[🔁 واجهت صعوبة]`: إعادة الجدولة لغداً للترسيخ.
  - `[🗑️ حذف]`: لحذف الموضوع وإلغاء مراجعاته.
- ✍️ **إضافة الكويزات يدوياً بدقة 100%:**
  - تحويل كويزات قنوات تيليجرام مباشرة للبوت مع حفظ الأجوبة والشروحات فوراً.
  - إنشاء كويز يدوي خطوة بخطوة.
  - استيراد وتصدير ملفات Excel و CSV عبر قوالب منظمة.
- ❌ **بنك الأسئلة الضعيفة:** توثيق أي سؤال يخطئ فيه الطالب لمراجعته وتكراره بشكل مستقل.
- 🔔 **تذكير يومي مجدول:** تنبيهات يومية بمراجعات اليوم في الموعد الذي يختاره الطالب بتوقيت مكة المكرمة.
- 📊 **إحصائيات فورية شاملة:** تتبع مستوى الإنجاز والترقي في مراحل الذاكرة.

## 🚀 الإعداد والتشغيل

### 1. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 2. إعداد متغيرات البيئة
انسخ `.env.example` إلى `.env` وأضف:
```env
TELEGRAM_BOT_TOKEN=your_token_here
ADMIN_USER_ID=your_telegram_id
```

### 3. تشغيل البوت
```bash
python bot.py
```

## 📁 هيكل المشروع
```
MemoryQudrat/
├── bot.py                  # تشغيل البوت والجدولة والتذكيرات

├── database.py             # طبقة قاعدة البيانات (SQLite / WAL Mode)
├── spaced_repetition.py    # خوارزمية وحسابات التكرار المتباعد

│   ├── main_menu.py        # القائمة الرئيسية والراوتر
│   ├── creation_handler.py # إنشاء الكويزات اليدوية وكويزات تيليجرام
│   ├── review_handler.py   # مراجعات اليوم والجدول الزمني
│   ├── quiz_handler.py     # جلسات حل الكويزات والتصحيح
│   ├── weak_handler.py     # بنك الأسئلة الضعيفة
│   ├── stats_handler.py    # إحصائيات الطالب والمستوى
│   ├── browse_handler.py   # تصفح الكويزات والمجلدات
│   ├── fixstage_handler.py # إدارة وتعديل مواعيد المراجعات
│   └── pdf_handler.py      # معالجة ملفات Excel و CSV والقوالب
└── requirements.txt
```
