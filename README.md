# MemoryQudrat 🧠 — منصة كويزات القدرات الذكية بالتكرار المتباعد

بوت تيليجرام لإدارة وحل كويزات القدرات والمذاكرة الذكية وفق منحنى النسيان (Spaced Repetition)، مصمم لضمان دقة 100% بدون أي تخمينات أو أخطاء للذكاء الاصطناعي وبدون إكسل.

## ✨ المزايا الرئيسية
- 👑 **حصر إضافة الكويزات في المشرف فقط:** واجهة متخصصة للأدمن لإنشاء ونشر الكويزات بـ 0% أخطاء.
- 🎯 **طرق إضافة كويزات قطعية وسريعة (Admin-Only):**
  - **كويزات تيليجرام الرسمية (Polls):** إرسال استطلاع كويز أو تحويله من أي قناة ليستخرج البوت السؤال والخيارات والإجابة والشرح فوراً بدقة 100%.
  - **الصيغة النصية السريعة (Smart Form):** لصق السؤال والخيارات في رسالة واحدة.
- 🚩 **نظام الإبلاغ الفوري عن أخطاء الأسئلة للطلاب:**
  - زر مخصص تحت كل سؤال: `[🚩 إبلاغ عن خطأ في هذا السؤال]`.
  - إشعار فوري في خاص المشرف برقم السؤال والخيارات لمراجعته وتصحيحه بنقرة واحدة.
- 🔁 **نظام التكرار المتباعد الذكي (Spaced Repetition):**
  - جدولة تلقائية لكل كويز يحله الطالب: غداً، ثم بعد 3، 7، 14، 30 يوماً.
- ❌ **بنك الأسئلة الضعيفة:** توثيق تلقائي لأي سؤال يخطئ فيه الطالب لمراجعته وتكراره حتى الإتقان.
- 🔔 **تذكير يومي مجدول:** تنبيهات يومية بمراجعات اليوم في الموعد الذي يختاره الطالب بتوقيت مكة المكرمة.
- 📊 **إحصائيات فورية شاملة:** تتبع مستوى الإنجاز والدرجات ونسب النجاح.

## 🚀 الإعداد والتشغيل

### 1. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 2. إعداد متغيرات البيئة
انسخ `.env.example` إلى `.env` وأضف:
```env
TELEGRAM_BOT_TOKEN=your_token_here
ADMIN_USER_ID=your_telegram_id
```

### 3. تشغيل البوت
```bash
python bot.py
```

## 📁 هيكل المشروع
```
MemoryQudrat/
├── bot.py                  # تشغيل البوت والجدولة والتذكيرات
├── config.py               # إعدادات النظام والمشرفين
├── database.py             # طبقة قاعدة البيانات (SQLite / WAL Mode)
├── spaced_repetition.py    # خوارزمية وحسابات التكرار المتباعد
├── handlers/
│   ├── admin_panel.py      # لوحة تحكم المشرف الموحدة ومنشئ الكويزات
│   ├── main_menu.py        # القائمة الرئيسية للطلاب والراوتر
│   ├── quiz_handler.py     # محرك حل الكويزات وزر الإبلاغ عن الأخطاء
│   ├── browse_handler.py   # تصفح الكويزات والأقسام للطلاب
│   ├── review_handler.py   # مراجعات اليوم وجداول التكرار المتباعد
│   ├── weak_handler.py     # بنك الأسئلة الضعيفة
│   ├── study_tracker.py    # رفيق المذاكرة الذكي وتسجيل الدروس
│   ├── stats_handler.py    # إحصائيات وتقدم الطالب
│   └── admin_handler.py    # خدمات الأوامر الإدارية والإذاعة والتحديث
└── requirements.txt
```
