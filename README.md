# MemoryQudrat 🧠 — رفيق المذاكرة الشخصي بالتكرار المتباعد

نظام شخصي نخبوي متكامل مبني كبوت تيليجرام لمساعدتك في استذكار وتثبيت مسائل ومفاهيم اختبار القدرات العامة (القسمين الكمي واللفظي) وفق منحنى النسيان والتكرار المتباعد (Spaced Repetition)، مع التركيز على **الالتقاط الفوري فائق السرعة** و **واجهة مراجعة خالية تماماً من التشتت**.

---

## ✨ الركائز الأساسية للنظام

1. **الالتقاط فائق السرعة لجميع الوسائط (Multi-Modal Zero-Friction Capture):**
   - **📸 تصوير المسائل:** التقط صورة أي مسألة أو سؤال وأرسلها فوراً في المحادثة، فتُحفظ وتُجدول تلقائياً لمراجعة الغد في ثانية واحدة.
   - **✍️ النصوص والقوانين:** أرسل أي فكرة، مسألة نصية، أو قانون لحفظه وجدولته.
   - **🔗 روابط الفورمز:** أرسل رابط Google Forms أو أي منصة تدريب ليُحفظ مع زر مباشر للحل والمراجعة.
   - **📑 ملفات الـ PDF:** أرسل مذكراتك وتجميعاتك لربطها بجدول المراجعة الذكية.

2. **نمطان منفصلان للمراجعة (Dual Review Modes):**
   - **نمط الأسئلة والمسائل (Active Recall / QA):** يعرض السؤال أولاً لإعطاء العقل فرصة الاسترجاع والحل، ثم زر `[ 💡 إظهار الحل / الشرح ]`، يليه تقييم فوري: `[ 🔴 نسيت/أخطأت ]` `[ 🟡 بجهد/متوسط ]` `[ 🟢 سهل ومتقن ]`.
   - **نمط المراجعة المباشرة (Direct Review):** مخصص لصور القوانين، خرائط المفاهيم، والملخصات؛ تُعرض الصورة ومباشرة تحتها أزرار التقييم الثلاثية دون الحاجة لزر كشف الإجابة.

3. **نظام المجلدات الذكي والأرشيف الدائم (Smart Folders & Archive):**
   - تنظيم مسائلك في مجلدات مرنة (مثل: `📐 قدرات كمي`, `📖 قدرات لفظي`, `💡 قوانين وقواعد`, `🎯 تجميعات 1446`).
   - خيار لمراجعة كل المستحق اليوم بضغطة زر واحدة، أو مراجعة مجلد محدد.
   - إمكانية الدخول لأي مجلد وتصفح مسائله وأرشيفه في أي وقت.
   - ميزة **"المجلد النشط"** لحفظ صورك في مجلدك المفضل تلقائياً دون أسئلة متكررة.

4. **تنبيهات مخصصة ونبض إحصائي يومي:**
   - تنبيه صباحي في الوقت الذي تفضله (افتراضياً 05:00 ص بتوقيت مكة) بعدد المسائل المستحقة مع زر للبدء المباشر.
   - لوحة إحصائيات تقيس ثبات الذاكرة (Retention Rate) وتوزيع المواد على مراحل التكرار (1، 3، 7، 14، 30 يوماً).

5. **خصوصية وأمان 100%:**
   - البوت شخصي وخاص ومقيد برقم معرّفك الحصري (`ADMIN_USER_ID`)، ويتجاهل أي وصول غير مصرح به.

## 🚀 الإعداد والتشغيل السريع

### 1. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 2. إعداد متغيرات البيئة
انسخ `.env.example` إلى `.env` وأضف توكن البوت ومعرف التيليجرام الخاص بك:
```env
TELEGRAM_BOT_TOKEN=your_bot_token_here
ADMIN_USER_ID=your_telegram_id_here
```

### 3. تشغيل البوت
```bash
python bot.py
```

### 4. تشغيل الاختبارات المؤتمتة
```bash
python -m unittest discover -s tests
```

## 📁 هيكلية المشروع النظيفة

```
MemoryQudrat/
├── bot.py                  # تشغيل البوت وإدارة التنبيهات المجدولة (JobQueue)
├── config.py               # الإعدادات وتخصيص الخصوصية
├── database.py             # طبقة قاعدة البيانات المبسطة (SQLite / WAL)
├── spaced_repetition.py    # خوارزمية التكرار المتباعد التكيفي وتوقيت الرياض
├── utils.py                # أدوات تنزيل الوسائط وتنظيف الشات التلقائي
├── handlers/
│   ├── capture_handler.py  # محرك الالتقاط الفوري (صور، نصوص، فورمز، مستندات)
│   ├── review_handler.py   # محرك المراجعة التفاعلية السلسة (QA & Direct)
│   ├── folders_handler.py  # إدارة المجلدات وتصفح الأرشيف في أي وقت
│   ├── stats_handler.py    # لوحة الإحصائيات الشخصية ونبض الذاكرة
│   └── main_menu.py        # اللوحة الرئيسية وتوجيه الأزرار والأوامر
├── data/
│   ├── photos/             # التخزين المحلي للصور الملتقطة (MD5 Hash)
│   └── documents/          # التخزين المحلي للمستندات والـ PDF
├── tests/
│   └── test_personal_system.py # حزمة الاختبارات المؤتمتة
└── requirements.txt
```

## 📋 الأوامر المتاحة داخل البوت

- `/start` أو `/menu` — فتح اللوحة الرئيسية النظيفة.
- `/review` أو `/today` — البدء الفوري في مراجعات اليوم المستحقة.
- `/folders` — استعراض المجلدات وتصفح المسائل المحفوظة.
- `/stats` — لوحة الإحصائيات ومعدل ثبات الذاكرة وموعد التنبيه.
- `/backup` — تصدير وتحميل نسخة احتياطية كاملة لقاعدة البيانات في الشات.
